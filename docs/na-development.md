# Na Cloud Agent Integration (Retired / 已退役)

> **状态说明**：Na 云端智能体（`na-cloud`）已从 OmniBot 客户端彻底退役并移除。原有的本地联调、Docker 部署、Composio 接入与多设备同步教程已废弃并归档。

## 退役概述

为聚焦端侧自主能力与本地化 Agent 架构，客户端已全面移除与 Na 云端服务相关的所有逻辑与界面：

1. **界面入口移除**：
   - 侧边栏抽屉与主会话模式菜单中已移除 Na 入口。
   - 移除了 Na 专属个人助理管理页面（`/home/na/personal`）与连接设置页面（`/home/na/connection`）。
   - 移除了 Composio 应用连接（Gmail、Calendar、Drive 等）与项目 Key 的客户端管理界面。

2. **客户端运行时与同步管道移除**：
   - 移除 `NaCloudRuntime`、`NaHistorySyncService` 及 `/api/events` 同步观察者。
   - 移除 Na 云端工作区文件浏览、下载与附件上传管道（`/api/files/uploads`）。
   - 移除原开发联调环境（`127.0.0.1:8787`、`adb reverse`）及相关 native 通道接口（`config/na/*`）。

## 数据与历史状态（隔离与保护）

- **旧 Na 本地历史未删但隔离隐藏**：
  历史版本中保存在设备本地数据库中的 Na 会话记录**并未物理删除，但已在客户端界面中完全隔离并隐藏**。普通对话列表和历史抽屉中不再呈现旧 Na 记录。
- **绝不转给其他 Agent**：
  隐藏的旧 Na 本地记录保持独立封存状态，**绝不会转移、合并或提供给其他 Agent 或通用聊天**，杜绝历史会话上下文污染。
- **普通本地历史与记忆不变**：
  普通本地会话历史、ACP 会话记录、本地工作区以及设备的短期与长期记忆嵌入（Memory Embedding）完全保持原状，不受任何影响。
- **远端服务器状态未操作**：
  本次变动为纯客户端架构精简，**未对远端 Na 服务器、云端工作区或 Docker 容器中的状态和数据执行任何删除或写操作**。

## 历史架构与部署教程归档（已废弃）

以下内容仅作为历史设计参考，不再作为当前客户端的有效指南：

- **历史调试端口**：原 `NA_PORT=8787`、`adb reverse tcp:8787 tcp:8787`。
- **历史构建参数**：`OMNIBOT_CLOUD_URL`（原默认 `https://na.omnimind.com.cn`）已废除。
- **历史外部服务**：原服务端 Composio 授权集成及 Google 应用审查流程已由客户端移除。
